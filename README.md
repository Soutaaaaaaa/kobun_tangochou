# 古文単語400

古文単語400語（No.1–400）を学ぶアプリ。Next.js (App Router) + TypeScript + Tailwind CSS + Supabase。スマホ表示を優先しています。

## できること

- **アカウント**：アカウント名とパスワードで新規作成・ログイン。学習記録はアカウントごとに保存。
- **20セクション**：最頻出語 1–100／頻出語 101–240／敬語 241–275／重要語 276–400。約20語ずつで、区分をまたがない。
- **単語カード**：フリック（タップ）でめくる → 覚えたら左、まだなら右へフリック。漢字表記はめくった後にだけ表示。めくった後に下へスクロールすると「似た意味の単語」（訳語が共通する語、`src/lib/similar.ts`）。縦の動きはスクロール、横の動きだけをカード操作として扱い、めくった直後の勢いあまったフリックは無視する。
- **中断・再開**：カード・クイズ・今日の復習は「中断」でいつでも止められる。1問ごとにこの端末へ自動保存され、トップの「中断中の学習」や同じ画面から続きを再開できる。
- **覚え方のコツ**：カードで「まだ」にした単語・クイズで間違えた単語に、語源・漢字・見分け方などのコツを小さく表示（全400語、`src/lib/tips-raw.ts`）。設定画面でオン／オフ（端末ごとに保存）。
- **四択クイズ**：形の似た語・意味の紛らわしい語を優先して選択肢に入れる。
- **ランダム出題**：既存の区分・セクションを複数選ぶか、番号（例：120〜180）を直接指定して、カード／クイズでランダムに出題。
- **今日の復習（40問）**：数日前に間違えた単語・苦手リスト・しばらく学習していない単語を優先して約7割、残りは普通の単語を混ぜて出題。
- **苦手リスト**：間違えた単語は自動で追加。2回連続で正解すると外れる（カードの「覚えた」も正解に数える）。手動でも出し入れ可。
- **出やすさの傾斜（非表示）**：今日の復習と苦手リストからの出題では、間違えた割合が高い単語・しばらく学習していない単語が少しだけ出やすい（`src/lib/weight.ts`、最大でおよそ2倍）。
- **連続学習日数・カレンダー**：トップに連続日数を重ねたほのお（日数が増えるほど大きくなる。今日まだ学習していないと灰色）。カレンダーで日ごとの学習量・最長連続記録を確認できる。1問でも答えた日を「学習した日」として数える。
- **設定**：覚え方のコツの表示切り替え、アカウント名とパスワードの変更（学習記録は引き継ぎ）。
- **管理者**：管理者アカウントは「管理」画面から全アカウントの進捗・苦手リスト・よく間違える単語・最近の解答を見られる（閲覧のみ）。
- **学習履歴**：単語ごとに「最後に学習した日時」「最後に正解した日時」「最後に間違えた日時」「正解数・不正解数」を保存。解答1回ごとのログ（study_logs）も保存。

## セットアップ

### 1. Supabase

1. [Supabase](https://supabase.com) でプロジェクトを作成。
2. **SQL Editor** で `supabase/migrations/` の `0001_init.sql` → `0002_grants.sql` → `0003_account_admin.sql` → `0004_weak_streak.sql` → `0005_study_days.sql` の順に中身を実行（テーブル・RLS・関数・権限・管理者機能を作成）。
3. **Authentication → Sign In / Providers → Email** で **「Confirm email」をオフ** にする。
   - Supabase のログインはメールアドレスが必須なので、アプリ内部では `…@kobun-tango.local` という実在しないアドレスを作って使っています（メールは送られません）。ログイン時はアカウント名からこのアドレスを引くので、アカウント名を変えてもログインできます。
   - もし Supabase がこのアドレスを受け付けない場合は、環境変数 `NEXT_PUBLIC_AUTH_EMAIL_DOMAIN` で別のドメインを指定してください。
4. **Settings → API** から Project URL と anon key を控える。

### 2. ローカルで動かす

```bash
cp .env.example .env.local   # URL と anon key を書き込む
npm install
npm run dev                  # http://localhost:3000
```

### 3. 公開する（例：Vercel）

GitHub のこのリポジトリを Vercel にインポートし、環境変数 `NEXT_PUBLIC_SUPABASE_URL` と `NEXT_PUBLIC_SUPABASE_ANON_KEY` を設定してデプロイします。

## 構成

```
src/
  app/
    login, signup          ログイン・新規作成（Server Actions: app/auth-actions.ts）
    (main)/                ログインが必要な画面
      page.tsx             トップ（セクション一覧・進捗）
      section/[id]         セクション詳細・単語一覧
      random               範囲を選んでランダム出題
      study                カード／クイズ（URLパラメータで範囲・出題数などを指定）
      review               今日の復習
      weak                 苦手リスト・間違えた記録
      calendar             学習カレンダー・連続日数
      account              アカウント名・パスワードの変更、ログアウト
      admin                管理者用：アカウント一覧・各アカウントの詳細
  components/              FlashCards, Quiz, WordList, ProgressProvider など
  lib/
    words-raw.ts           単語データ（番号|見出し|漢字|品詞|意味;意味…）
    words.ts               カテゴリ・セクション分け
    distractors.ts         紛らわしい選択肢の選び方
    review.ts              今日の復習の出題ロジック
    supabase/              Supabase クライアント（ブラウザ・サーバー・middleware）
  middleware.ts            未ログインなら /login へ
supabase/migrations/       DB スキーマ
```

### データベース

| テーブル | 内容 |
|---|---|
| `profiles` | アカウント名・管理者フラグ（サインアップ時に自動作成） |
| `word_progress` | ユーザー×単語ごとの状態：苦手か、正解数・不正解数、連続正解数、最終学習・最終正解・最終不正解の日時 |
| `study_logs` | 解答1回ごとの記録（単語・正誤・カード/クイズ/今日の復習・日時） |

どのテーブルも Row Level Security で本人の行しか読み書きできません（管理者は全員分を読み取りのみ可）。

### 管理者の追加・解除

SQL Editor で実行します。アカウント名は小文字で保存されるので、小文字で書いてください。

```sql
update public.profiles set is_admin = true  where username = 'admin';   -- 管理者にする
update public.profiles set is_admin = false where username = 'admin';   -- 解除する
```

解答の記録は `record_answer` 関数で、状態の更新とログの追加を1回で行います。
