# 古文単語400

単語帳の索引（No.1–400）をもとにした古文単語学習アプリ。`index.html` をブラウザで開くだけで動きます。

- 20セクション（最頻出語 1–100／頻出語 101–240／敬語 241–275／重要語 276–400、区分をまたがない）
- 単語カード：フリック（タップ）でめくる → 覚えたら左、まだなら右へフリック
- 四択クイズ：形の似た語・意味の紛らわしい語を優先して選択肢に入れる
- 学習記録はブラウザ（localStorage）に保存

編集は `src/words.txt`（単語データ）と `src/app.html`（画面）で行い、`python3 build.py` で `index.html` を生成します。
